# Home Assistant Nest Integration

This is a private, personal-use application that connects the owner's Google Nest thermostat to a self-hosted Home Assistant system. It is not offered as a public service.

The application uses only permissions approved by the owner to read Nest device information and events and to carry out device commands initiated by authorized household users through Home Assistant. It does not sell data, use data for advertising, or provide access to third parties.
